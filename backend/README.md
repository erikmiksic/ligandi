# Backend

Python API koji povezuje ekstrakciju, bazu podataka i frontend.

## Postavljanje

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Pokretanje

_(dopuniti kad se odabere framework, npr. `uvicorn app.main:app --reload` za FastAPI)_
