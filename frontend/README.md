# Frontend

React + TypeScript sučelje za pregled, ispravak i potvrdu izdvojenih podataka.

## Inicijalno postavljanje (radi se samo jednom)

Iz korijena repozitorija:

```bash
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install
```

## Pokretanje

```bash
cd frontend
npm install
npm run dev
```
